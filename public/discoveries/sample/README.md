# Sample discovery artwork (SAMPLE — replace)

These SVGs are placeholder illustrations drawn for the Kinnit prototype. They
are **not** approved brand assets and **not** photographs of anyone.

To use real images, drop JPG/WebP files into `public/discoveries/<topic>/` and
update the topic's `images` list in `src/app/config/discoveryTopics.ts`.
Each image needs descriptive `alt` text. Topics with no images fall back to an
icon treatment automatically.
